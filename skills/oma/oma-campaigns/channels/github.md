# GitHub: channel rules

Checked 2026-11-24.

## Who publishes
The publisher, through the GitHub integration: pull requests, releases and approved replies on the brand's own repositories. Pull requests to other projects, such as awesome lists, go out only after approval.

## Rules
- Spam and inauthentic activity are banned. No bulk or unsolicited issues, pull requests or comments on other people's repositories, and no fake stars, forks or accounts.
- A pull request to someone else's list follows that list's contribution guide: one entry, in the right section, in their format.
- Replies on issues answer the actual problem, link to docs or a fix, and say when something is a known limitation.
- Release notes describe what changed, with breaking changes first.

## Limits
- At most 1 pull request per external list, and no resubmission after a rejection.
- Never ask for stars in exchange for anything.
