# Humanizer

This package vendors [blader/humanizer v4.0.0](https://github.com/blader/humanizer/tree/b48c832f0f809c1b5658edbb838c2521b72f2413) under its [MIT license](LICENSE). OMA seeds it into the shared skill library under `writing/humanizer`. Its skill ID is `humanizer`.

OMA assigns `humanizer` to campaign roles that prepare public copy. The role uses the skill in embedded mode before it hands off a finished draft. Campaign guidance supplies the brand voice and the publication workflow.
